# UI 术语表

维护日期：2026-08-12  
来源：`docs/product/current-page-layout-audit.md` P2-1。本表是面向 UI 的术语决策记录，视觉文案与无障碍名称必须与之一致。

## 唯一含义

| 术语 | 唯一含义 | 使用位置 |
|------|---------|---------|
| 面试工作台 | 以 Agent 对话流为核心的工作区主页面 | 侧栏、移动端页栏、工作台页头 |
| 项目 | 被上传/分析的代码仓库或作品 | 全局 |
| 项目资料 | 项目结构、技术栈、流程与证据的查阅页 | 侧栏、页级页头 |
| 岗位准备 | 目标岗位与专项题库管理页 | 侧栏、页头 |
| 简历库 | 面试者简历的 master-detail 管理页 | 侧栏、页头 |
| 复盘会话 | 一次项目复盘/面试会话（名词） | 新建复盘会话页 |
| 会话报告 | 一次会话的后端评价报告页 | 侧栏、页头、加载/失败/空状态文案 |
| 能力画像 | 面试者跨会话能力汇总页 | 侧栏、页头 |
| 应用设置 | 应用级大模型与 Agent 配置页；不得称为"工作区设置" | 侧栏、页级页头 |
| 新建复盘 | 创建新复盘会话的动作按钮 | 侧栏主操作 |

## 文案规则

- 应用级模型与 Agent 配置只出现在"应用设置"下，页头标题与导航名一致。
- 输入区按状态变化：无项目时引导"告诉 Agent 你的准备重点"，可回答时显示"你的回答"。
- 加载/失败/空状态标题与导航名一致（如"会话报告"），不引入同义变体。

## 已统一项（2026-08-12）

- 设置页页头标题："工作区设置" → "应用设置"。
- 侧栏与移动端页栏："会话复盘" → "会话报告"。
- 会话报告页的 aria-label、眉题与加载/失败/空状态标题：统一为"会话报告"。
- 空工作台输入区标签："和 Agent 开始对话" → "告诉 Agent 你的准备重点"。

## 保留词（有意保留，非漂移）

- "面试工作台"：产品核心工作区概念，审计未提供替代词。
- "新建复盘"：动作按钮，与名词"复盘会话"区分。
- "复盘报告"类表述仅出现在后端返回内容或历史文档中，不作为 UI 术语。
